# 知见 RAG 产品原型（审核稿）

打开 `rag-prototype.html` 可查看核心工作台。该页面模拟了用户完成登录后最常用的一次闭环：上传资料、等待解析、提出问题、查看带定位信息的引用。

## 信息架构

| 页面 | 用户目的 | 原型内呈现 |
| --- | --- | --- |
| 登录 | 使用企业账号进入指定工作区 | 顶部个人信息、工作区名称；正式实现将补充独立登录页和 SSO/手机号分支 |
| 知识问答 | 提问并核验答案 | 主工作台中心区；每个引用均可定位至右侧原文证据 |
| 我的文档 | 上传、查看版本与资料状态 | 右侧资料库卡片和上传弹层；正式页会承载筛选、批量操作与文档详情 |
| 解析任务 | 追踪文件解析、分片与索引异常 | 左侧一级入口；正式页采用任务列表和失败重试视图 |
| 团队与权限 | 管理成员与资料可见范围 | 左侧一级入口；正式页采用成员表和资料范围规则 |

## 视觉方向

- 名称：**知见**。面向内部团队的、可追溯的知识工作台。
- 配色：深海蓝 `#162846`（工作区）、检索蓝 `#246BFF`（行动）、纸页白 `#FFFEFA`（内容）、雾灰 `#EDF1F6`（背景）、证据绿 `#267A58`（已核验）。
- 字体：标题使用思源宋体风格，承载“文档/知识”；正文为清晰的中文无衬线，证据编号和状态使用等宽字体。
- 交互签名：**证据带**——模型答案中的 `[1]`、`[2]` 可点击并定位到对应的原文证据，不把引用藏在答案末尾。

## 审核建议

重点确认产品名称、深蓝 + 纸白的方向、资料库放在问答页面右侧的效率，以及引用定位是否足以建立可信感。确认后，前端实现将把原型替换为可用的登录、上传、解析进度和真实问答接口。
